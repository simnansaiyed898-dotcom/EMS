# Event Registration System
WAD Practical 12 mini project.

## Run
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:3000`.

SQLite database `events.db` is created automatically.

## Features
- Add, edit, delete and search events
- Event capacity and available seats
- Participant registration
- Duplicate/full-event validation
- Registration records and cancellation
- Dashboard statistics
